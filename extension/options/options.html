Connection troubleshooting
  1. In Anki: Tools → Add-ons → Get Add-ons → code 2055492159, then restart Anki.
  2. If connecting still fails, open Tools → Add-ons → AnkiConnect → Config and add this extension's origin to webCorsOriginList:
  3. Keep Anki open while adding words.

Getting started

  1. Click the KhmerLens toolbar icon to turn it on for the current tab — the badge shows ON.
  2. Hover over any Khmer word and the popup appears with its definition.

Keyboard shortcuts

AltK
Toggle KhmerLens on the current tab (rebind at chrome://extensions/shortcuts)
Shift
Cycle to shorter / alternative matches
C
Copy the word and definition
N
Jump to the next word
S
Play pronunciation (bundled recording, or the system's Khmer voice if installed)
A
Add the word to Anki (when Anki integration is enabled)
Esc
Hide the popup
